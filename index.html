Data Engineering Track · Bootcamp

Modern Data Engineering

From raw sources to a governed, AI-ready lakehouse: ingest, model, test, scale, stream, orchestrate and govern data with the open tools data teams use today.

Data Engineering Track 4 teaching days × 4h + capstone day 16 training hours 16 hands-on labs in Python and SQL

One case study, all week

Qafila is a fictional quick-commerce grocery platform in Riyadh, Jeddah and Dammam. Its data arrives the way real data does: an app database, a paginated payments API, a CDC feed, a courier event stream, weekly supplier files and bilingual reviews, each with deliberate problems. Every lab adds a piece to one platform. All data is synthetic, so the labs run offline and nobody handles real personal data.

Ingest

DuckDB, Parquet, dlt, incremental loads, CDC and SCD2

Model

DuckDB & Polars, star schemas, dbt, tests and contracts

Scale & stream

Apache Iceberg, Spark, event time, watermarks, streams into the lakehouse

Operate

Dagster, observability, data contracts, PDPL & NDMO governance, data for AI

Demonstrate

Team capstones: a working platform, live demo, technical Q&A

Capstone

Teams of 2–3 build a working data platform, choosing one of:

  • Qafila Lakehouse: batch + streaming platform from raw sources to governed marts and a near-real-time operations view
  • Open Data Platform: Saudi open datasets in a lakehouse with tests, a semantic layer and a small dashboard
  • Real-time Operations Monitor: event-time KPIs, SLA alerts, an Iceberg history table and replay

Minimum: two source types, one command end to end, a layered model with documented grain, idempotent incremental loads, 8+ tests or contract checks, orchestration and a governance note. Starter kit with a working Dagster pipeline: labs/capstone/.

Rubric

Functional end-to-end pipeline30%
Architecture & data modeling decisions25%
Data quality, testing & observability20%
Orchestration, governance & operability15%
Presentation & reproducibility10%

Participants will be able to

  • Design a modern data platform and choose between warehouse, lake and lakehouse
  • Build incremental, idempotent ingestion from databases, APIs, files and CDC feeds
  • Model data dimensionally and transform it with dbt, tested and under contract
  • Work with open table formats (Iceberg) and decide when Spark or streaming is worth it
  • Orchestrate, monitor and govern pipelines under PDPL and NDMO requirements
  • Prepare governed, AI-ready data: semantic layers, embeddings and safe text-to-SQL

Setup

Audience: Python- and SQL-proficient developers, analysts and data scientists moving into data engineering. No prior Spark, dbt, orchestration or streaming experience needed.

Environment: any laptop CPU with uv, or Google Colab. No Docker or cloud account; Java 17+ only for the Spark lab (on Colab the lab installs it). Run 00_setup_check before Day 1; see labs/README.md.

Stack: DuckDB · Polars · Parquet / Arrow · dlt · dbt + dbt-duckdb · Apache Iceberg (PyIceberg) · PySpark 4 · Pandera · Dagster · ODCS data contracts · model2vec · an OpenAI-compatible LLM endpoint (optional).
