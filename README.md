# Modern Data Engineering

**SDAIA Academy · Data Engineering Track**: a 4-day hands-on bootcamp (4 sessions per day) plus a capstone presentation day. From raw sources to a governed, AI-ready lakehouse: ingest, model, test, scale, stream, orchestrate and govern data with DuckDB, Polars, dlt, dbt, Apache Iceberg, Spark and Dagster.

**Course page and slides:** https://sdaiaacademy.github.io/data-engineering/

| Day | Theme | Slides |
|---|---|---|
| 1 | Data Platforms, Storage & Ingestion | [day1](https://sdaiaacademy.github.io/data-engineering/slides/day1.html) |
| 2 | Transformation, Modeling & Quality | [day2](https://sdaiaacademy.github.io/data-engineering/slides/day2.html) |
| 3 | Lakehouse, Scale & Streaming | [day3](https://sdaiaacademy.github.io/data-engineering/slides/day3.html) |
| 4 | Production: Orchestration, Reliability, Governance & AI | [day4](https://sdaiaacademy.github.io/data-engineering/slides/day4.html) |
| 5 | Capstone Project Presentations | [day5](https://sdaiaacademy.github.io/data-engineering/slides/day5.html) |

Each day runs Session 1 → short break → Session 2 → mid-day break → Session 3 → short break → Session 4. Every session is about 20–25 minutes of concepts and demos followed by a 25-minute lab. Break slides default to 10 minutes (20 for the mid-day break); the instructor can change the length or type a "back at" time on the slide.

**Slide keys:** `F` fullscreen · `Esc` exit · `←` `→` / `↑` `↓` navigate · `N` speaker notes · `O` overview · `T` start/pause timer · `?` help.

The whole week follows one case study: **Qafila**, a fictional quick-commerce grocery platform in Riyadh, Jeddah and Dammam, with synthetic data generated by `labs/prepare_data.py`. [OUTLINE.md](OUTLINE.md) has the full outline and the research behind it.

## Repository

```
index.html          course page (GitHub Pages)
OUTLINE.md          course outline and the research behind it
slides/             one HTML deck per day
assets/             slide engine (deck.css, deck.js) and logo
labs/               notebooks, data generator, dbt project, shared helpers, capstone kit (see labs/README.md)
```

Labs run on any laptop CPU with [uv](https://docs.astral.sh/uv/) or on Google Colab (one click from the course page): see [labs/README.md](labs/README.md).

Add `?check` to a deck's URL to run its layout self-check. It flags overflowing slides and clipped code lines.
